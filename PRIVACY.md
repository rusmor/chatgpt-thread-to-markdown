# Privacy Policy

ChatGPT Thread to Markdown does not collect, transmit, sell, or store user data.

## Data handling

- Conversation content is processed locally in the active browser tab.
- The extension makes no network requests.
- The generated Markdown file is downloaded through the browser to the user's normal downloads folder.
- No conversation content, URLs, usage statistics, identifiers, or diagnostics are sent to the developer or to a third party.

## Browser permissions

The extension uses `activeTab` and `scripting`. Access is granted temporarily only after the user clicks the extension icon, and only for that active tab. The extension does not request persistent access to browsing history or website content.

## Third-party service

The extension operates on pages provided by ChatGPT. Use of ChatGPT remains subject to OpenAI's own terms and privacy policies. This project is independent and is not affiliated with OpenAI.

## Changes

Material privacy changes will be documented in the repository and release notes.
