## Chrome Web Store

### Title

ChatGPT Thread to Markdown

### Summary

Export long ChatGPT conversations to clean Markdown with one click—open source, private, and tracking-free.

### Detailed description

ChatGPT Thread to Markdown exports the active conversation to a clean `.md` file with one click.

It is designed for long conversations. The extension automatically scrolls through the current thread, collects messages that ChatGPT virtualizes out of the page, and restores the scroll position when the export is complete.

Key features:

- Export long ChatGPT conversations to Markdown
- Preserve User and Assistant roles
- Preserve headings, lists, links, blockquotes, code blocks, inline code, tables, and available LaTeX source
- Include the source conversation URL and export timestamp
- Process everything locally in the active browser tab
- No analytics, tracking, remote code, or network requests
- No persistent access to ChatGPT or browsing history
- Open-source under the MIT License

The extension exports only the currently selected conversation branch. Uploaded images and files are not embedded in the Markdown output.

This is an independent, unofficial project. It is not affiliated with or endorsed by OpenAI.
